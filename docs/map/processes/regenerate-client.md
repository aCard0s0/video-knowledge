# regenerate-client

Turning a server API change into a typed console client. Three of its four steps are automatic and
the fourth is the one that gets forgotten.

## Input → Movement → Output

A changed controller. The **running** server's springdoc spec is curled to a committed snapshot and
openapi-generator rewrites `src/app/api/generated/`. Output is a typed client — plus a manual pass
over `core/domain.ts` that no tool performs.

## Why this shape

The spec is fetched from a live server, not built offline, so the new code must be **deployed
before** the client can know about it. And two flags are not optional:

- `--type-mappings=set=Array` — without it a Java `Set` (`skipPhases`) generates `Set<string>`, and
  `JSON.stringify(new Set(['OCR']))` is `"{}"`. The field silently reaches the server as an object
  and the request 400s.
- an explicit `@Operation(operationId = …)` on every method — without it springdoc derives ids from
  method names, they collide across controllers, and the client gets `list1()`, `get2()`, `_delete()`.

## Steps

1. Add the path constant to `VidIngestApiPaths` — never inline a literal
   (`applications/vidingest/vidingest-api/.../paths/VidIngestApiPaths.java`).
2. Add `@Operation(operationId = …)` to the controller method.
3. Start the server, then `cd applications/webapp && npm run api:gen` — the `api:gen` and
   `api:codegen` scripts in `applications/webapp/package.json`.
4. **Manual:** if a server enum gained a constant, add it to
   [`core/domain.ts`](../objects/console/domain-enums.md). Nothing fails if you skip this — the
   console just stops recognising the value at runtime.
5. Commit `openapi/vidingest.json` and the generated tree **together**.

## If you change this

- **Hits:** the whole console. Also `core/problem.ts` if an error body moved — no operation
  documents a 4xx/5xx, so those stay `any` regardless.
- **Does not hit:** `vidingest-client` (the **Java** client). It is hand-written against
  `VidIngestApiPaths` and is not regenerated by this at all — a step 1 that skips the constant
  breaks it silently.

## Surfaces

| Surface | Role |
|---|---|
| `npm run api:gen` | writes `src/app/api/generated/` wholesale |
| a human | writes `core/domain.ts` |
