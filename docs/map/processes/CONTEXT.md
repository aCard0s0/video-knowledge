# processes — the five movements

One job: answer *how does X happen* with numbered, cited steps.

## Inputs
- Working: the movement you were asked about
- Reference: [`../objects/_index.md`](../objects/_index.md) for the nouns each step touches

## Process
1. Pick the movement from the table below.
2. Read its steps. Each cites `path:line`.
3. For the nouns, follow the links out — this shelf does not restate cards.

## Outputs
Nothing. A new card is a copy of [`../_templates/process.md`](../_templates/process.md), and only
for a movement that **actually runs**.

## Human check
Five is the count because five is what runs. If you are about to add a sixth, name the code path
that executes it — an aspirational verb is a `ghost` and does not get a card.

## The five

| Movement | Input → Output | Card |
|---|---|---|
| **ingest-run** | URLs → a run, items, and everything derived | [ingest-run.md](ingest-run.md) |
| **re-execute** | a finished or failed thing → the same thing, again | [re-execute.md](re-execute.md) |
| **reap** | abandoned work → FAILED, or left alone | [reap.md](reap.md) |
| **channel-sync** | a channel URL → candidate videos | [channel-sync.md](channel-sync.md) |
| **regenerate-client** | a server API change → a typed console client | [regenerate-client.md](regenerate-client.md) |
